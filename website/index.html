Satellite research

Exploring satellite imagery to flag possible oil spills for closer review.

  • PyTorch
  • Segmentation
Read case study for Satellite research↗
The problem
A suspicious region in a satellite image needs a closer look before anyone can draw a conclusion.
My work
Comparing segmentation models in PyTorch, testing checkpoint recovery and running inference experiments.
Approach
Observe → Screen → Context → Investigate
Project notes
A private research prototype, illustrated here with synthetic imagery.
In context
Screened regions are candidates for investigation, not confirmed oil spills. Imagery alone cannot establish which vessel was responsible.

The approach

  1. ObserveStart with satellite imagery.
  2. ScreenHighlight candidate regions with image analysis.
  3. ContextConsider each region alongside supporting information.
  4. InvestigateLeave the final interpretation to a human reviewer.

03 / 03

Hackathon demo

Vendor Payment Memory Agent

Reusing past invoice resolutions to help review recurring payment exceptions.

  • FastAPI
  • Hindsight
Read case study for Vendor Payment Memory Agent↗
The problem
Recurring invoice exceptions often mean searching for the same resolution again.
My work
Built a FastAPI demo that recalls past resolutions, checks GSTIN, HSN and purchase-order fields, and suggests a next step for human review.
Approach
Receive → Recall → Suggest → Review
Project notes
Public hackathon demo using example invoices and vendors.
In context
Example records are demonstration data, not client records. Suggestions need human review. The demo does not authorise or execute payments.
View demo code ↗

The approach

  1. ReceiveStart with an invoice exception.
  2. RecallRetrieve context through Hindsight or a local JSONL fallback.
  3. SuggestUse earlier resolutions to suggest an approach.
  4. ReviewLeave the decision with a human reviewer.
